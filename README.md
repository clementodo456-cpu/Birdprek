# 🌟 Daily Motivation Telegram Bot (@BirdPrekChakV99SBS24bot)

A production-ready Telegram Bot built with **Python 3.11+**, `python-telegram-bot` (v20+ async), **SQLite**, and **APScheduler**. The bot delivers curated motivational quotes and daily positive messages based on user delivery preferences and timezones.

---

## ✨ Features

- **Automated Daily Motivation:** Sends quotes daily based on the user's local timezone and chosen time.
- **On-Demand Quotes:** Generate random motivational quotes instantly using `/motivate`.
- **100+ Offline Quotes:** Includes a built-in library of 100 quotes (no external API required).
- **Consecutive Duplicate Prevention:** Tracks quote history to prevent repeating the same quote twice.
- **Timezone & Schedule Customization:** Interactive inline keyboard time and timezone selector.
- **Admin Tools:** Broadcast announcements, check user stats, and view registered users.
- **Render Ready:** Pre-configured with persistence disk support so scheduled jobs and user preferences survive redeployments/restarts.
